# Simulación y análisis de señales con la Transformada de Fourier

## Descripción
Este proyecto tiene como objetivo simular y analizar señales en los dominios del tiempo y de la frecuencia mediante Python y la Transformada Rápida de Fourier (FFT).

## Objetivos
- Generar señales elementales.
- Representar gráficamente las señales en el dominio del tiempo.
- Calcular los espectros de magnitud y fase.
- Comprobar propiedades de la Transformada de Fourier.

## Señales analizadas
1. **Pulso rectangular:** señal que mantiene una amplitud constante durante un intervalo.
2. **Función escalón:** señal que cambia de cero a uno a partir de un instante determinado.
3. **Señal senoidal:** señal periódica de 5 Hz.

## Herramientas utilizadas
- Python
- NumPy
- Matplotlib
- Kaggle Notebooks

## Propiedades estudiadas
- Linealidad.
- Desplazamiento temporal.
- Escalamiento temporal y su efecto en la frecuencia.

## Ejecución
El código se encuentra en el cuaderno de Python incluido en este repositorio. Para ejecutarlo, abre el archivo `.ipynb` en un entorno compatible con Python y ejecuta sus celdas en orden.

## Conclusión
La simulación permite observar cómo las señales se representan en el dominio del tiempo y en el dominio de la frecuencia. La Transformada de Fourier facilita el análisis de sus componentes frecuenciales y ayuda a comprender propiedades importantes del procesamiento de señales.
